# biographies

人物别卷：[陈到功成 · 来回之间，未完的一页](https://biographies.maniforld.com/chen-chengfeng/)。

页面位于 `chen-chengfeng/`。以梁博星的第一人称视角写成六章纪实散文：题头、真的、未完、不知道、一个暑假、学长。保留原对话的节奏和日常细节，以前后照应串起相识、协作、互相答疑与交接。所有新增引语已按本地记录核对，不补写人物内心、动作或未见场景。

以“来回”组织阅读：封面可切换三次真实对话的回应方向，六章分别展开题头、感叹号、深夜时刻、答案返回、暑假约定与名单之后。每章旁边有可逐步查看的行动路径，共十九个步骤；每步标明人物、行动、引语说话人及出处。未解问题、转述、并行帮助、未来约定和同届名单均区分表达。可切换“只读文字”，保持当前段落的位置。完整关系图继续保留七条事件路线、八位具名人物、未署名的答疑老师与工作群；老师问答使用转述点线，名单使用无箭头虚线。十六组出处可展开核对。

静态 HTML/CSS/JavaScript，无构建依赖。支持键盘、原生弹层、减少动画与矮屏布局。完整原始聊天、附件与联系方式不进入本仓库。

Static GitHub Pages deployment for `凝结核·列传：人物篇十二传`.
